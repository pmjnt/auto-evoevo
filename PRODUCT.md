# Auto EvoEvo Product Context

## Register

Product.

## Users

Power users operating a dedicated Chrome profile and burner wallet to automate EvoEvo memory intake on 0G.

## Core Job

Run Feed and Predictions workflows safely, sequentially, and repeatedly without relying on browser tab automation.

## Product Character

Quiet, precise, operational, and trustworthy. The interface should disappear into the task.

## Design Principles

- Put current state, next action, and failure recovery first.
- Use one restrained orange accent only for primary actions and focus.
- Keep controls familiar, compact, keyboard accessible, and stable at 380px.
- Prefer separators and grouped rows over decorative or nested cards.
- Preserve explicit safety controls such as dry-run, fee caps, Pause, and target selection.

## Anti-References

- AI-purple gradients, glows, glass panels, and decorative blobs.
- Marketing heroes, oversized headings, feature copy, and equal card grids.
- Excessive rounding, soft shadows, one-note orange or brown palettes.
- Hidden validation, ambiguous status colors, clipped labels, and layout shifts.

## Accessibility

Target WCAG AA contrast, visible keyboard focus, text labels for state, reduced motion compatibility, and no color-only meaning.
